Interface :

- when we create the same name interface it will merge together :

Example:

  name : string;

interface User{
  email? : string;

interface ButtonProps {
  children: React.ReactNode;
  handleOnClick: () => void;
  MyClassName?:string;
  variant?: "default" | "primary" | "error";
}
