2. Add smother-scroll in the class 
in the react we use : className="smooth-scroll" to create the class CSS 

Ex1: use css class : Styles  

+ In layout.tsx 

export default function RootLayout({
  children,
}: Readonly<{
  children: React.ReactNode;
}>) {
  return (
    <html lang="en" className="smooth-scroll">
      <body
        className={`${geistSans.variable} ${geistMono.variable} antialiased`}
      >
        {children}
      </body>
    </html>
  );
}

+ In the globals.css 

.smooth-scroll{
  scroll-behavior: smooth;
}
