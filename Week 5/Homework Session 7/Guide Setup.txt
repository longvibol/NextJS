How to Connect from NextJS to Postgress with docker!

1- Create docker image :

"docker-compose.yml"

version: "3.8"

services:
  postgres:
    image: postgres:16
    container_name: postgres_container
    restart: always
    environment:
      - POSTGRES_USER=admin
      - POSTGRES_PASSWORD=admin
      - POSTGRES_DB=mydatabase
    ports:
      - "5432:5432"
    volumes:
      - postgres_data:/var/lib/postgresql/data

volumes:
  postgres_data:

1-1 Run command to create postgress db 

>> docker-compose up -d

or 

>> docker compose -f docker-compose.yml up -d


------------------------------------------------------------------------

2- Connection to database 

Host: 127.0.0.1 or localhost 
user:  admin

5-Connect to your database

Initialize the driver and make query

>> npm i drizzle-orm pg
>> npm i -D drizzle-kit @types/pg

5-1 Create connection from our app to postgress :

- install dotenv 
>> npm install dotenv

- create file ".env" in the root folder 

syntax:

postgresql://<username>:<password>@<hostname>:<port>/<database_name>

==> DATABASE_URL=postgresql://admin:admin@127.0.0.1:5432/mydatabase


- Create a drizzle.config.ts file in the root of your project and add the following content:

drizzle.config.ts

----------------------------------------------

import { config } from 'dotenv';
import { defineConfig } from "drizzle-kit";

config({ path: '.env' });

export default defineConfig({
  schema: "./src/app/db/schema.ts",
  out: "./drizzle",
  dialect: "postgresql",
  dbCredentials: {
    url: process.env.DATABASE_URL!,
  },
});


----------------------------------------------- 



- Create a drizzle.ts file in your src/db folder and set up your database configuration:

------------------------------------------------------------------

drizzle.ts 


// Make sure to install the 'pg' package 
import { config } from "dotenv";
import { drizzle } from "drizzle-orm/node-postgres";
import { Pool } from "pg";

config({ path: ".env" }); // or .env.local

const pool = new Pool({
  connectionString: process.env.DATABASE_URL,
});

export const db = drizzle({ client: pool });

-----------------------------------------------------------------

schema.ts 

-----------------------------------------------------------------

import { integer, text, boolean, pgTable } from "drizzle-orm/pg-core";

export const todo = pgTable("todo", {
  id: integer("id").primaryKey(),
  text: text("text").notNull(),
  done: boolean("done").default(false).notNull(),
//   done is the name in the JS and "done" is the table name in postgress
});


-----------------------------------------------------------------
